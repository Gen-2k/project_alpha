# Product Hypotheses & Validation Framework

This document defines the core product, market, and technical hypotheses that must be experimentally validated before and during the implementation of **Project Alpha**.

---

## 1. Core Hypotheses & Validation Experiments

| Hypothesis ID | Category         | Core Hypothesis Statement                                                                                                                                                             | Validation Experiment                                                                                          | Target Success Metric                                                   |     Status      |
| :------------ | :--------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------- | :-------------: |
| **HYP-01**    | AI Quality       | Providing AST metadata, glossaries, and top-3 TM matches to frontier LLMs (RAL) achieves MQM $\ge 90$ on $\ge 75\%$ of standard software UI strings across 10 diverse language pairs. | Run a blind evaluation on 5,000 real-world open-source software strings comparing raw DeepL vs. RAL Prompting. | $\ge 75\%$ of RAL strings score $\ge 90$ with 0 critical syntax errors. | **In Progress** |
| **HYP-02**    | DX & Adoption    | Developers will adopt a CLI and GitHub Action that automatically creates localized branch companion PRs with zero manual JSON copy-pasting.                                           | Onboard 5 beta engineering teams to test the `alpha push / pull` GitHub Action in their daily sprints.         | $\ge 80\%$ of PRs merged without manual developer intervention.         |   **Backlog**   |
| **HYP-03**    | Commercial Fit   | Mid-market tech companies currently paying \$15k–\$30k/year to Lokalise or Phrase will switch to Project Alpha for unlimited keys, branch isolation, and automated MQM triage.        | Conduct 20 customer discovery interviews with VPs of Engineering and Localization Leads.                       | $\ge 40\%$ express intent to switch or pilot within 60 days.            |   **Backlog**   |
| **HYP-04**    | Review Velocity  | In-country marketing reviewers will complete reviews $4\times$ faster when reviewing via interactive visual DOM preview compared to a spreadsheet table.                              | Usability A/B test with 15 regional reviewers comparing time-to-approve across 50 UI screens.                  | Average review time per screen drops by $> 60\%$.                       |   **Backlog**   |
| **HYP-05**    | Branch Isolation | Virtual copy-on-write branch modeling completely eliminates string merge conflicts during fast-paced Git rebasing.                                                                    | Synthetic load test simulating 50 concurrent Git feature branches making simultaneous string modifications.    | 0 duplicate keys, 0 lost translations, 0 Git merge conflicts.           |   **Backlog**   |
