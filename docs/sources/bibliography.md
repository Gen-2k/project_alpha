# Research Sources & Standards Bibliography

This document provides the complete bibliography of technical standards, industry market reports, academic literature, and competitor disclosures referenced across the **Project Alpha** research repository.

---

## 1. Official Standards & Specifications

1. **Unicode Consortium:**
   - _Unicode Common Locale Data Repository (CLDR) v45+_: Definitive specification for plural rules, locale identifiers, collation, and date/number formatting.
   - _Unicode Technical Standard #35_: Unicode Locale Data Markup Language (LDML).
   - _ICU MessageFormat Specification_: Standard syntax for dynamic interpolation, select blocks, and pluralization.
   - _Unicode Standard Annex #29_: Unicode Text Segmentation (Grapheme cluster, word, and sentence boundaries).
2. **Quality & Localization Industry Standards:**
   - _W3C / ASTM F2575 Standard Practice for Quality Assurance in Translation_: Multidimensional Quality Metrics (MQM) taxonomy and error weighting.
   - _OASIS XLIFF 2.1 Standard_: XML Localisation Interchange File Format.
   - _ISO 17100:2015_: Translation services — Requirements for translation services.
   - _ISO 18587:2017_: Translation services — Post-editing of machine translation output.
   - _ISO 30042_: Management of terminology resources — TermBase eXchange (TBX).
   - _IETF BCP 47 (RFC 5646)_: Tags for Identifying Languages.
   - _RFC 9562_: Universally Unique IDentifiers (UUIDv7 Specification for Monotonic Primary Keys).
